# Assets needed for the website

The homepage has five empty screenshot boxes. The October 2026 shots were removed because the art is not final (`a30b0c7`). Do not put those files back.

When a shot is final, replace the matching placeholder:

`<div class="placeholder">Screenshot</div>`

with:

`<img src="images/FILE.png" alt="Short description">`

| Slot | File | Caption on the page |
| --- | --- | --- |
| First large box | `images/game-window.png` | The game window. |
| Gallery, first | `images/sign-in.png` | Sign-in. |
| Gallery, second | `images/whispers.png` | Whispers. |
| Gallery, third | `images/skills.png` | Skills. |
| Gallery, fourth | `images/skill-reset.png` | A skill reset. |

Use a wide image, about 1200 pixels across. The empty box is 16:9. A real image keeps its own shape.
